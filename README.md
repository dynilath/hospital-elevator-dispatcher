# 🏥 医院电梯调度员 · HOSPITAL ELEVATOR DISPATCHER

> 第一人称 3D 像素复古风的医院电梯调度模拟游戏

你是一名电梯调度员,在 8:00–17:00 的一天里接听来电、接送病人、处理紧急任务,还要应付各种难缠的家属——把满意度维持住,成为金牌调度员。

技术栈:**React 19 + Three.js + TypeScript + Vite**,纯前端、零资源文件(音效由 Web Audio 实时合成)。

[▶ 在线试玩](https://dynilath.github.io/hospital-elevator-dispatcher/)(GitHub Pages)

## 🎮 玩法简介

- **一天的工作**:游戏内 8:00–17:00 被压缩为 5–10 分钟,高峰时段(8:00–10:00 / 14:30–16:30)任务生成明显提速。
- **第一人称视角**:在轿厢内**按住鼠标拖拽**环视,**点击**道具与乘客交互。
- **📱 手机来电**:任务通过右下角手机通知——点「接听」在悬浮窗打字播报,点「挂断」结束;任务记录在旁边的 **📋 调度夹板** 里。
- **🚨 紧急任务**:带倒计时,急救床可无视容量直接上梯,优先处理,超时会重罚。
- **🛏️ 乘客类型**:站立 / ♿ 轮椅 / 卧床(病床)/ 担架(急救床);卧床和担架必带家属或护士陪护,陪护会自己按楼层按钮。
- **📢 拥挤管理**:空间不够时用左下角 **「📢 往里走走」/「➡ 靠右站站」** 让人挪位——乘客不一定会配合,病床与「阿巴阿巴」的患者永远不动,不配合者会头顶弹气泡吐槽。
- **📋 调度夹板** 与 **「医院楼层分布」贴画**:查看任务记录与各层科室分布(拟真难度下无记录,需自行记忆)。
- **🎭 剧情电话**:领导急召(VIP,上梯前满意度持续衰减)、恶作剧骚扰电话、工勤拖沓来电、家属堵门(点他头顶「🚫 别堵门!」劝离)、挑剔家属(到站前必须点「😊 微笑服务」,否则被开除)。
- **点击乘客**可以问目的地。

### 计分与评级

| 项目 | 规则 |
|---|---|
| 满意度(满分 100) | 领导急召上梯前 −1/秒;普通任务等待超 20s 宽限期后 −0.22/秒;紧急超时 −12;取消家属呼叫被斥责 −3(随机);送达 +1(普通)/ +2(紧急) |
| 评级公式 | `pct = 0.45 × 满意度 + 0.35 × 紧急成功率 + 0.2 × 完成率` |
| 评级 | **S** ≥ 0.85 金牌调度员 · **A** ≥ 0.7 优秀调度员 · **B** ≥ 0.55 合格调度员 · 否则 **C** 需要加油 |

倒计时结束后进入**加班阶段**(不再生成任务,服务完所有人才结算);也可点「收工」提前结束(不评级)。

| 自定义 | 4–12 层 | 低 / 中 / 高 | 时长 5–10 分钟、拟真开关 |

## 🛠️ 电梯特性

- **格子制容量**:轿厢 3 × 4 = 12 格(调度员自己占后角 1 格);站立 1 格、轮椅 4 格、病床 / 担架 8 格。
- **真实物理**:加/减速与巡航速度模拟真实电梯,上下客耗时因乘客类型而异(站立 1.0s、轮椅 1.7s、病床 2.6s、担架 2.2s)。
- **顺向优先调度**:优先响应行进方向的呼叫,顺向清空后翻转方向;支持带方向(▲/▼)的厅外呼叫,再点一次可取消。

## 🕹️ 操作一览
